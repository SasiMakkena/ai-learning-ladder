# AI Learning Ladder

A phone app for learning AI terms, level 1 to 10, with quizzes and analogies.

- `index.html` is the whole app. Change it here and the Android app picks it up the next time it opens.
- `version.json` tells the Android app whether a newer APK exists. Raise `apkVersionCode` only when you upload a new APK.
- APKs must be signed with the AI Ladder signing key kept in 1Password.
